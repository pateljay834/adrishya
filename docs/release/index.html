the traceless system

A Debian-based live operating system that is amnesic by default, routes everything through Tor, and leaves no trace on the machine it runs on. Built for the journalist, researcher and activist - with Indic localisation and censorship-resistance tuned to Indian networks.

Amnesic by default Tor only Wayland-only 22 Indic languages GPL-3.0

What it is, and what it is not

Adrishya boots from a USB stick into RAM. Nothing is written to the internal disk, no traffic leaves without Tor, and the memory is wiped on shutdown. It keeps the guarantees that make Tails trustworthy and adds six targeted improvements, each independently testable.

Wayland-only

The X11 server is removed, closing the global screenshot and synthetic-input surface Xorg exposes.

Confined apps

Bundled apps run in Flatpak sandboxes with seccomp, Landlock, and their own network namespace.

Stable-per-network MAC

Randomises per session, or derives a stable address from the SSID so you are not a new device on every boot.

Modern bridges

obfs4, WebTunnel and Snowflake, fetched through Moat with domain fronting - tuned to Indian ISP blocking.

Strong persistence

Optional LUKS2 storage with Argon2id, a detached-header option, and a VeraCrypt-compatible hidden volume.

Indic first-class

All 22 scheduled languages, Indic input, and bundled fonts - not an afterthought.

Honest status. Adrishya is a build-ready source tree, not a released distro. It has not had an independent security audit, and a from-scratch OS is not more trustworthy than Tails on day one. Do not rely on it for high-stakes anonymity until it has been audited.

Get it running

Build in the cloud

Push the source to GitHub and let its runners build the ISO. No Linux machine of your own needed - download the finished image to Windows.

Build in a VM

On any machine: spin up a Debian VM (QEMU or VirtualBox + Vagrant) and run the build there. The repository ships both definitions.

On a Debian host

Already on Linux? One command:

sudo apt install live-build
./scripts/fetch-tor-browser.sh 14.5.7
sudo make build

Verify before you trust

Every release ships a signed checksum and an SBOM. Rebuild it yourself and compare - identical inputs must give identical bytes.

sha256sum -c adrishya-*.iso.sha256
gpg --verify adrishya-*.iso.asc
